# نظام التحكم في الجودة والإنتاج — Web App

هذه النسخة جاهزة للنشر على **GitHub Pages**.

## التشغيل على GitHub Pages

1. أنشئ مستودع GitHub جديد.
2. ارفع الملفات الثلاثة الرئيسية: `index.html` و`manifest.webmanifest` و`sw.js`، مع هذا الملف.
3. من **Settings → Pages** اختر النشر من فرع `main` والمجلد `/ (root)`.
4. افتح رابط GitHub Pages الناتج.

## ملاحظة مهمة حول البيانات

الإصدار الحالي يحتفظ بالبيانات داخل متصفح الجهاز باستخدام IndexedDB مع localStorage كبديل. لذلك فإن GitHub Pages لا يجعل البيانات مشتركة بين الهواتف والحواسيب تلقائياً.

للحصول على **قاعدة بيانات مركزية وتزامن لحظي بين جميع الأجهزة** يجب إضافة Backend/API وقاعدة PostgreSQL أو خدمة Backend مُدارة، ثم ربط هذا الواجهة بها. يمكن تنفيذ ذلك كمرحلة ثانية دون إعادة تصميم الواجهة بالكامل.

## الأمان

لا تضع كلمات مرور أو مفاتيح API أو أسرار قاعدة البيانات داخل `index.html` أو مستودع GitHub عام. بيانات الدخول الحالية في النسخة المحلية تخص المتصفح نفسه وليست بديلاً عن مصادقة خادمية.
